## 常见问题

**搬瓦工优惠码的“循环折扣”是什么意思？**

循环折扣指用优惠码购买后，这台机器以后每次续费都按折扣价计算，等于终身享受同等折扣。搬瓦工近年大部分常规码都是循环折扣，只有少数活动码（如 2022 年元旦码、2020–2021 年部分节日码）注明续费原价。

**优惠码可以用于续费和升级吗？**

可以。循环折扣码适用于购买、套餐升级和续费，续费和升级时会自动应用首购时使用的优惠码。已付款订单不能事后补用。

**搬瓦工可以一次买多年吗？**

不可以。搬瓦工采用国外通用的账单模式，最长按年购买。VPS 到期后系统会在一周内生成新账单并以邮件通知，在一周内续费即可。

**为什么现在搜不到搬瓦工优惠码？**

因为官方在 2025 年双十一后取消了常规优惠码机制，目前只在 11 月活动节点或特定合作时短暂放出。平时看到标注“最新可用”的旧码，大概率已经失效，下单前在购物车验证一下即可确认。
